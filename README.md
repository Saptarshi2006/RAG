# 🔎 RAG

**Retrieval-Augmented Generation experiments** — chunking strategies, embedding
retrieval and grounded LLM answers over private document sets.

</div>

---

## 🎯 What this explores

- **Ingestion** — loading and chunking source documents
- **Retrieval** — semantic search over embeddings, top-k selection, reranking
- **Generation** — grounding LLM answers strictly in retrieved context
- **Evaluation** — faithfulness & relevance of answers against the source corpus

## ▶️ Getting started

```bash
git clone https://github.com/Saptarshi2006/RAG.git
cd RAG
pip install -r requirements.txt
```
